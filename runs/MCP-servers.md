# MCP Servers Study Notes

## Introduction to MCP Servers
MCP (Model Control Protocol) serves as a tool to expose functionalities to a model. `server.py` defines these tools and their functionalities.

**TL;DR**: MCP exposes tools to a model and enforces permissions.

## Tools Exposed by MCP
- MCP exposes various tools to interact with the model.
- `server.py` defines these tools.

**TL;DR**: MCP exposes tools to a model.

## Permissions Enforcement
- The harness enforces permissions to ensure secure interactions with the model.

**TL;DR**: The harness enforces permissions.

## Skills Package for Workflow Automation
- Skills package allows for repeatable workflows.
- This enables consistent and automated handling of tasks related to MCP servers.

**TL;DR**: Skills package enables repeatable workflows.
